# 💬 Диалог без границ: учебный помощник в Telegram

Проект создан для **Конкурса студенческих проектов «СтудПедОлимп»** по кейсу **«Диалог без границ»**.

Это Telegram-бот, через который студенты и преподаватели общаются, не теряя информацию в чатах. Преподаватель загружает заметку: объявление о пересдаче, дедлайн или ведомость с результатами. Нейросеть разбирает её на отдельные факты и привязывает их к группам. Студент спрашивает обычными словами, например «Когда пересдача по математике?» или «Сдал ли я контрольную?», и получает ответ по актуальным заметкам своих преподавателей.

---

## ✨ Возможности

### 🧑‍🎓 Студент
- Регистрация: ФИО, курс и группа (например, `3 ИСИП 124`), фото студенческого билета.
- Вопросы боту в свободной форме: ответ строится только на заметках, загруженных для его группы.
- Просмотр, редактирование и удаление своего профиля.

### 👨‍🏫 Преподаватель
- Регистрация: ФИО и специальность.
- Загрузка заметок текстом или файлом (`.docx`, `.txt`), включая таблицы и ведомости.
- Управление заметками: переименование, замена содержимого, удаление.
- Нейросеть сама определяет, к какой группе и курсу относится заметка, и разбивает ведомость на отдельные записи по каждому студенту.

### 🛡️ Администратор
- Проверка заявок студентов (по фото студенческого билета) и преподавателей: одобрить или отклонить, с листанием между заявками.
- Список всех пользователей с ролями и статусом верификации.

### Для всех
- `/help`: справка с темами для конкретной роли (как зарегистрироваться, что делать, если заявку отклонили, как загрузить заметку и т.д.).
- `/profile`: просмотр данных, редактирование (с повторной проверкой) и удаление профиля с подтверждением.

## 🤖 Как работает ИИ

```
Преподаватель                        Студент
     │                                  │
     │  заметка / файл .docx, .txt      │  «Когда пересдача?»
     ▼                                  ▼
┌──────────────────────┐      ┌──────────────────────────┐
│ gpt-oss-120b         │      │ выборка записей для      │
│ разбирает текст      │      │ группы студента          │
│ в JSON: группа, курс,│      └────────────┬─────────────┘
│ тема, суть, дата     │                   ▼
└──────────┬───────────┘      ┌──────────────────────────┐
           ▼                  │ gpt-oss-20b              │
   записи в SQLite  ────────► │ отвечает только по этим  │
                              │ записям                  │
                              └──────────────────────────┘
```

1. **Структурирование.** Заметка преподавателя превращается в набор объявлений с полями «группа», «курс», «тема», «содержание», «дата события». Если в тексте таблица с результатами, нейросеть создаёт отдельную запись на каждого студента.
2. **Ответ.** На вопрос студента бот выбирает последние объявления для его группы (и общие для всех) и передаёт их модели. Модель отвечает только по ним, а если ответа нет, так и говорит, ничего не придумывая.

Модели работают через [Groq API](https://groq.com) (OpenAI-совместимый интерфейс).

## 🧭 Команды

| Команда | Кому | Что делает |
|---|---|---|
| `/start` | всем | Регистрация и выбор роли |
| `/help` | всем | Справка по темам |
| `/profile` | зарегистрированным | Профиль: просмотр, редактирование, удаление |
| `/student` | студентам | Задать вопрос боту |
| `/teacher` | преподавателям | Меню заметок |
| `/admin` | администраторам | Проверка заявок и список пользователей |

## 🛠️ Технологии

- **C# / .NET 8**
- **[Telegram.Bot](https://github.com/TelegramBots/Telegram.Bot)**: работа с Telegram Bot API
- **Entity Framework Core + SQLite**: хранение пользователей, заметок и объявлений
- **OpenAI SDK + Groq**: модели `openai/gpt-oss-120b` и `openai/gpt-oss-20b`
- **DocumentFormat.OpenXml**: чтение `.docx`, включая таблицы

### Структура проекта

```
dialogue_without_borders_tg_bot/
├── Program.cs              # запуск бота, обработка команд и кнопок
├── AI.cs                   # разбор заметок и генерация ответов через Groq
├── Classes.cs              # модели: пользователи, заметки, объявления
├── ApplicationContext.cs   # контекст базы данных (EF Core)
└── config.example.json     # пример файла настроек
```

## 🚀 Запуск

### 1. Что понадобится
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- Токен бота от [@BotFather](https://t.me/BotFather)
- API-ключ [Groq](https://console.groq.com/keys)

### 2. Установка

```bash
git clone https://github.com/nel1nn/study-assistant-bot.git
cd study-assistant-bot/dialogue_without_borders_tg_bot
```

Скопируйте `config.example.json` в `config.json` и подставьте свои значения:

```json
{
  "ConnectionStrings": { "DefaultConnection": "Data Source=Message.db" },
  "BotConfiguration":  { "BotToken": "ВАШ_ТОКЕН_ОТ_BOTFATHER" },
  "GroqConfiguration": { "ApiKey": "ВАШ_КЛЮЧ_GROQ" }
}
```

> ⚠️ `config.json` указан в `.gitignore`. Не публикуйте его: в нём токен бота и ключ API.

### 3. Запуск

```bash
dotnet run
```

База данных SQLite создаётся автоматически при первом запуске. Чтобы корректно остановить бота, нажмите `Enter` в консоли: незавершённые действия пользователей в меню сбросятся.

### 4. Первый администратор

Стать администратором через бота нельзя, это сделано намеренно. Первого администратора добавьте вручную одним из способов:
- раскомментируйте блок `AdminDB` в начале `Program.cs`, укажите свой Telegram ID и запустите бота один раз;
- или добавьте запись в таблицу `Users` базы данных со значением `Discriminator = AdminDB`.

Свой Telegram ID можно узнать, например, у бота [@userinfobot](https://t.me/userinfobot).

## 📋 Известные ограничения

- Объявления подбираются по специальности и номеру группы без учёта курса, поэтому студенты разных курсов с одинаковым названием группы видят общие записи.
- Записи из ведомости доступны всей группе, а не только конкретному студенту.
- Права администратора проверяются при открытии меню `/admin`, но не при каждом нажатии кнопки проверки заявок.
- Состояние диалога хранится в базе данных, поэтому нажатия на кнопки в очень старых сообщениях могут не сработать.
